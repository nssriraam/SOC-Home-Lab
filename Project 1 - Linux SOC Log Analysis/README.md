# Project 1 – Linux SOC Log Analysis

## Overview
This project focuses on hands-on Linux log analysis from a SOC analyst perspective. The goal was to understand how system and authentication logs can be used to detect suspicious activity, brute-force attempts, and abnormal system behavior.

---

## Tools & Environment
- Linux (Ubuntu)
- journalctl
- auth.log
- syslog
- grep, awk, cut
- Bash commands

---

## What I Did
- Analyzed system logs using `journalctl`
- Investigated SSH authentication attempts via `auth.log`
- Identified failed and successful login patterns
- Filtered logs using grep and time-based queries
- Practiced SOC-style log triage techniques
